# Premium learning resources

This is the paid layer of Uncoding: a cleaner, more focused learning system for engineers who want better outcomes without the random content chaos.

## Public learning

The public site remains free and open for general learning:

- Java notes and concept explanations
- system design reading material
- interview preparation resources
- roadmap-style learning paths

## Premium access

Premium access is for people who want a faster path and more direct guidance.

### 1. Notes Pack

A compact study package for practical revision.

Includes:

- Java interview notes
- system design cheat sheets
- problem-solving references
- PDF-based summary guides

Price: $49

### 2. Interview Mastery Bundle

A stronger product for serious prep.

Includes:

- full interview roadmap
- Java + system design study pack
- curated questions and revision cycles
- stronger preparation structure

Price: $149

### 3. Mock Interview + Career Support

For engineers who want real feedback before the actual rounds.

Includes:

- resume review
- mock interviews
- system design feedback
- backend career guidance

Starting at $79 per session

## How this works

The public site builds trust. The premium layer turns that knowledge into a real product.

- Free content = trust and discovery
- Premium products = structured value and better conversion
- Mock support = higher-value service layer

## Recommended path

1. Use the free notes to learn the foundations
2. Follow a roadmap that matches your target role
3. Upgrade to the premium bundle when you want sharper structure
4. Add mock interview support before your live rounds

> Important: GitHub Pages is public by design. The premium layer should live on a separate gated platform such as Gumroad, Memberful, ConvertKit, or a private portal when you are ready to sell access. The public site remains the storefront and trust layer.
