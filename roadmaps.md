# Learning roadmaps

These roadmaps are designed to help you study with intention instead of collecting random notes.

## Java interview roadmap

1. Core Java fundamentals
2. Collections and data structures
3. Streams and functional programming
4. Concurrency and multithreading
5. Design patterns and clean code
6. System-level thinking and tradeoffs
7. Mock interview practice and revision

## System design roadmap

1. Fundamentals of distributed systems
2. Databases, caching, and storage choices
3. APIs and service boundaries
4. Scalability patterns and bottlenecks
5. Reliability and failure handling
6. Tradeoff analysis and design communication
7. Practice with problem-based design questions

## DSA and problem solving roadmap

1. Arrays and strings
2. Hashing and maps
3. Trees and graphs
4. Recursion and backtracking
5. Dynamic programming
6. Heap and greedy patterns
7. Mock practice and reflection

## Recommended order

Start with fundamentals, then move to applied interview preparation. Do not try to learn everything at once. Build a loop around:

- learn
- revise
- practice
- reflect on weak areas
